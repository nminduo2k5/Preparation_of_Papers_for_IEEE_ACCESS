Vì mình đã hiển thị hai dạng so sánh trong ô “Gap”:

giá thứ nhất là Pred − Act (chênh giữa dự báo và giá thực tế),
giá thứ hai là Pred − Start (chênh giữa dự báo và giá tại Start).
Ví dụ: \textcolor{green}{(\uparrow)+1.75 / (\uparrow)+0.55} nghĩa là Pred−Act = +1.75 (mũi tên/ màu cho so sánh Pred vs Act) và Pred−Start = +0.55 (mũi tên/ màu cho so sánh Pred vs Start).
